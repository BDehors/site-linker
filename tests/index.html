 场景 02

打开前：两个最常见的“看不到效果”

① 本地文件页（file://）默认不跑内容脚本。三种解法任选：在 edge://extensions 打开本扩展的“允许访问文件 URL”；或者在本目录跑 python -m http.server 8000，然后访问 http://localhost:8000/tests/；或者直接把本套件部署到任意 http 站点。
② 更新过词典或代码后没重新加载。去 edge://extensions 点扩展卡片的“重新加载”，再刷新页面（F5）。

关于 PDF / Word：一个需要了解的技术事实

浏览器内置的 PDF 查看器和 Office 文件预览器不运行扩展脚本，任何内容脚本类扩展都进不去。所以对 PDF / Word 这类文档，本套件的做法是：把出处直接做进文档本身（PDF 的链接注释、Word 的超链接字段），在浏览器里打开照样可以点击跳转。
想体验“站点名自动变链接”的效果，请用网页版（场景 02）——同一篇文章、同一批出处，对照着看最直观。
样例文件由 tools/make-samples.py 从 article.html 自动生成，改完文章重新跑一次即可。

还想再压一层？

① 点工具栏上的扩展图标：弹窗里可以输入站点名直接搜索打开官网（试试输 steam 或 淘宝）；也可以勾选 / 取消分类（比如关掉“政府与数据”），已打开的页面不刷新也会立即变化。
② 进扩展设置页（edge://extensions 里点“扩展选项”）：「点击链接时」是自动复制/粘贴的总开关；「我添加的站点」只收纳你自己加的站点（和词库分开）；「站点修正」改词库条目的网址、触发词或停用。改完回本页刷新，立刻见效。
③ 自动复制验收：打开 场景 02 拉到“顺手一试：点击链接自动复制”一段，点其中的豆瓣链接——“三体”会被复制，新窗口打开豆瓣后在那个窗口里点搜索框即自动粘贴（可粘多次，换窗口不粘）。
④ 一句多个引号验收：打开 场景 01 第 11 题，点题面里的“中国知网”链接——“数字经济”与“税收”两个词会一起被复制（空格相连），打开知网后粘进高级检索的检索框即可。
本套件所有内容均为原创示例（含练习题与文章情节），仅用于验证“站点链接助手”的链接化效果；文中站点链接均指向各平台官网。
