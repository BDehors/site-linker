站点链接助手

选择启用哪些站点分类，默认全部开启。可以只留学术类，也可以全开。修改即时保存，并同步到同一账号的其他浏览器；已打开页面中的链接会按新设置立即重排。

点击链接时

点击网页里变成链接的站点名时，自动把这一句话里 《书名号》、引号（“”「」） 里的内容（有多个会全部复制，空格相连），或站点名后冒号（：）之后的内容复制到剪贴板；官网打开后，在点击链接时新打开的那个窗口里，点一下搜索框等输入框就会自动粘贴——可以粘多次（高级检索有几个检索框就粘几次），换到别的窗口不粘。10 分钟内有效，不会粘回原来那个页面。抄书单、搜片名不用再来回复制——不需要就取消勾选。

点击链接时直接新开一个浏览器窗口，位置自动避让：当前窗口左半屏吸附就放右半屏、右半屏吸附就放左半屏，普通大小的窗口则紧挨着当前窗口放；多显示器等拿不准坐标的场景按系统默认级联。中键点击、Ctrl / ⌘ + 点击仍按浏览器默认开新标签页。不需要就取消勾选。两个开关互相独立，上面的复制功能照常生效。

信源体检

在 DeepSeek、Kimi、豆包、腾讯元宝、通义千问、文心一言、Perplexity、ChatGPT 的对话页上，回答下方会出现一张体检卡：列出这条回答引用了哪些站点、各自属于哪一档、为什么这么判，可以逐条打开或复制。 判档只看域名认不认得（权威词典 325 站 + 网信办许可名单 + 政府教育后缀 + 社区名单）， 只输出等级和理由，不判断内容真假；“未收录/待核”不代表是假网站，只代表插件没法替你确认。 回答里提到来源却没给链接的，单独一行标出来，不占三档。 体检与台账全部在本机完成，插件不发任何网络请求；取消勾选即回到 v1 行为。

台账：读取中…

体检卡上点“这是官网（反馈误报）”后，那个域名下次直接算“官方/权威”——这是给你的误判留的纠正口子，反馈同样只存在本机。

我添加的站点

这里只放你自己添加的站点，与上面的词库分类、下面的“站点修正”完全分开——时间久了也一眼看清哪些是自己加的。弹窗里的“自定义站点”分类就是用来整体开关这些站点的。

站点修正

词库由社区维护，难免有疏漏。发现网址不准确、想补充触发词、或要停用词库自带条目，都在这里改——修改保存在你自己的浏览器里，插件更新不会覆盖。自己添加的站点请在上方“我添加的站点”里管理。

批量更新与备份

① 从 Excel / 表格里直接复制「资源名称、提示词、网址」三列（列之间为制表符）粘贴到下框：名称与词库条目完全一致 = 修正该条（改网址、补触发词）；名称不一致 = 新增为自定义站点（进入“我添加的站点”）。
② 导出 / 导入 JSON 可用于备份，或把修正分享给其他人（新旧格式都能导入）。
